# Agent instructions for this site

The site is plain HTML generated by `build.py` from the YAML files in `content/`. GitHub Pages serves the `docs/` folder on `master`.

## Updating the site

1. Edit the right file in `content/` (never edit `docs/` by hand):

   | Request | File |
   | --- | --- |
   | Home-page intro, contact, links, "Join us" | `content/site.yml` |
   | Research themes, funding, collaborators | `content/research.yml` |
   | Group members, alumni, how we work, PI bio | `content/people.yml` (photos in `static/images/group/`) |
   | Papers | `content/publications.yml` (newest first) |
   | Courses and terms taught | `content/teaching.yml` |
   | News | `content/news.yml` (newest first; the home page shows the first 6) |
   | Education, positions, awards, talks, service, media | `content/cv.yml` |

2. Run `python build.py` (needs Python 3 and PyYAML). `python build.py --serve` previews at http://localhost:8000.
3. Check the changed page in a browser, then commit `content/` and `docs/` together and push to `master`. Pages rebuilds in about a minute.

## Rules

- The source of truth for career facts is `Portfolio/` in Y. Zheng's Obsidian vault (Second Brain). Never invent facts; when the user gives a new fact, also record it in the Portfolio.
- Public content only: no pending or declined proposals, manuscripts under review, review or committee details, student grades, evaluation scores, or application status.
- New paper: add it at the top of `content/publications.yml` with the next `P##` ID from `Portfolio/Publications.md`; mark supervised students and postdocs with `<u>…</u>` and the corresponding author with `*`. Add its ID to a theme in `research.yml` if it is a key paper.
- Course numbers follow the official numbers in `Portfolio/Teaching.md`.
- Do not use pronouns for people unless they are stated. Write in English.
- Push only with Y. Zheng's approval.
